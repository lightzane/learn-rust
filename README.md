# Concurrency

Reference: <https://doc.rust-lang.org/book/ch16-00-concurrency.html>

Learn how you can use the following:

- `std::thread` + `thread::spawn` + `move` keyword on _closures_
- `std::sync::mpsc` (multi-producer single consumer)
- `std::sync::{Arc, Mutex}` = `Mutex<T>` and `Arc<T>`
