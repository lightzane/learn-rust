# Cargo Workspaces

Reference: <https://doc.rust-lang.org/book/ch14-03-cargo-workspaces.html>

Workspace is a set of packages that share the same `Cargo.lock` and output directory.

This exercise will contain a binary and two libraries.

- binary will contain the `main.rs`
- library 1 will contain `add_one`
- library 2 will contain `add_two`

## Lesson Notes

### Creating a Workspace

```bash
mkdir learn-rust
cd learn-rust
```

### Create `Cargo.toml` in root directory

`Cargo.toml`

```toml
[workspace]
resolver = "3"
```

Point to the latest version of Cargo's resolver algorithm. (must be a string)

### Create `adder` binary crate

```bash
# cargo new <pkg_name>
cargo new adder
```

**Result**

```bash
 Creating binary (application) `adder` package
      Adding `adder` as member of workspace at `path\to\learn-rust`
note: see more `Cargo.toml` keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html
```

**Notice:**

- It modified the root `Cargo.toml`

```diff
  [workspace]
  resolver = "3"
+ members = ["adder"]
```

- `adder` directory was created with: `Cargo.toml` and `src/main.rs`, etc.

`adder/Cargo.toml`

```toml
[package]
name = "adder"
version = "0.1.0"
edition = "2024"

[dependencies]

```

**Summary tree**

```txt
├── Cargo.lock
├── Cargo.toml
├── adder
│   ├── Cargo.toml
│   └── src
│       └── main.rs
└── target
```

> Note: `Cargo.lock` and `target` may not yet be auto-generated at this time

### Create the Second Package in the Workspace

```bash
# cargo new <pkg_name> --lib
cargo new add_one --lib
```

**Result**

```bash
Creating library `add_one` package
      Adding `add_one` as member of workspace at `path\to\learn-rust`
note: see more `Cargo.toml` keys and their definitions at https://doc.rust-lang.org/cargo/reference/manifest.html
```

**Notice**:

- it modifies the root `Cargo.toml`

```diff
  [workspace]
  resolver = "3"
+ members = ["add_one","adder"]
```

> `"add_one"` is the newly added member.

- `add_one` directory was created with: `Cargo.toml` and `src/lib.rs`, etc.

`add_one/Cargo.toml`

```toml
[package]
name = "add_one"
version = "0.1.0"
edition = "2024"

[dependencies]

```

**Summary tree**

```txt
├── Cargo.lock
├── Cargo.toml
├── add_one
│   ├── Cargo.toml
│   └── src
│       └── lib.rs
├── adder
│   ├── Cargo.toml
│   └── src
│       └── main.rs
└── target
```

> Note: The `Cargo.lock` and `target` may still not yet be auto-generated by this time

### Create a function in `add_one/src/lib.rs`

```rs
pub fn add_one(x: i32) -> i32 {
    x + 1
}
```

Now we can have the `adder` package depend on the `add_one` package

### Add a path dependency

`adder/Cargo.toml`

```toml
[dependencies]
add_one = { path = "../add_one" }
```

We can now use it in `adder/src/main.rs`

```rs
fn main() {
    let num = 7;
    println!("{num} plus one is {}", add_one::add_one(num))
}

```

### Cargo Run

To run the binary crate from the root directory, we can specify which package in the
workspace we want to run by using the `-p` argument and the package name

```bash
# cargo run -p <pkg_name>
cargo run -p adder
```
